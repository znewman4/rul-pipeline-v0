# Stage 2 — Synthetic forward library and measurements (`rul_pipeline.synthetic`)

**Role:** exercise and validate the inversion machinery before the BristolFE library exists. Nothing here is used once real data are available, except `add_measurement_noise` for controlled noise studies.

## 1. Toy FMC forward model (`forward_toy.py`)

A **ray-based, two-scatterer** model with the *structure* of a real FMC dataset (tx × rx × time, geometric arrival times, array of realistic size) and a smooth dependence on $a$. It is **not** a physical scattering model.

### Configuration (defaults)

| Parameter | Value | Rationale |
|---|---|---|
| array | 64 elements, 1-D linear, pitch 0.6 mm | ≈ λ/2 for L-waves in steel at 5 MHz (λ = 1.18 mm), avoids grating lobes ([Drinkwater & Wilcox, 2006](https://doi.org/10.1016/j.ndteint.2006.03.006)) |
| centre frequency | $f_c$ = 5 MHz, 5-cycle Hann toneburst | typical NDT array |
| material | steel, $c_L$ = 5900 m/s | BristolFE examples use steel ($E$ = 210 GPa, $\nu$ = 0.3) |
| specimen | 20 mm plate, backwall-breaking crack at $x = 0$ | fatigue cracks typically initiate at the surface |
| sampling | $f_s$ = 25 MHz, time window gated around the defect echoes | 5× $f_c$ keeps the 64×64 FMC to about 640k samples |

A 1-D linear array is used because BristolFE v2 is a **2-D plane-strain** code. A 2-D matrix array would need a 3-D forward model.

### Equations

Element centres $x_e = (e - \tfrac{n-1}{2})\,p$ at $z = 0$. The scatterers are the **crack tip** $(x_c, T-a)$ and the **corner trap** $(x_c, T)$. For scatterer $s$ at distance $r_e$ from element $e$, with incidence angle $\theta_e$ ($\cos\theta_e = z_s/r_e$):

```math
F_{tr}(t; a) = \sum_{s\in\{\text{tip},\text{corner}\}} A_s(a)\,
\frac{\cos\theta_t\cos\theta_r}{\sqrt{r_t r_r}/T}\;
w\!\left(t - \frac{r_t + r_r}{c}\right),
\qquad
w(\tau) = \cos(2\pi f_c\tau)\cos^2\!\left(\frac{\pi\tau}{2\tau_{1/2}}\right)\mathbb{1}_{|\tau|\le\tau_{1/2}}
```

with $\tau_{1/2} = n_\text{cyc}/(2f_c)$, $A_\text{tip} = 0.3$ and $A_\text{corner}(a) = 1 - e^{-a/\lambda}$, so the corner echo vanishes for $a \ll \lambda$. The factor $1/\sqrt{r}$ is 2-D cylindrical spreading, and $\cos\theta$ is a crude element directivity.

```python
def scatterer(z, amp):
    r, cos_t = legs(z)                                        # (n_el,) distances and cosines
    delay = (r[:, None] + r[None, :]) / c                     # (tx, rx)
    gain = amp * (cos_t[:, None] * cos_t[None, :]) / np.sqrt(r[:, None] * r[None, :] / thickness**2)
    return gain[..., None] * toneburst(time[None, None, :] - delay[..., None], f_c, n_cycles)

for i, ai in enumerate(a):
    corner = corner_amplitude * (1.0 - np.exp(-ai / lam))
    responses[i] = scatterer(thickness - ai, tip_amplitude) + scatterer(thickness, corner) + backwall
```

`toy_fmc_truth(a_true, lib)` evaluates the same model at an **off-grid** $a_\text{true}$ on the library's time base. This avoids the most blatant "inverse crime" (inverting data generated by the identical discretised model at a grid point; [Kaipio & Somersalo, 2007](https://doi.org/10.1016/j.cam.2005.09.027)).

## 2. Noisy measurement (`measurement.py`)

```math
y = F(a_\text{true}) + e
```

### Noise level: exactly one of three specifications

| Argument | Definition |
|---|---|
| `sigma` | absolute $\sigma$ (unit of $y$) |
| `rms_fraction` | $\sigma = \rho\,\mathrm{RMS}(F(a_\text{true}))$ |
| `snr_db` | $\sigma = \mathrm{ref}/10^{\mathrm{SNR}/20}$, with ref = $\max\lvert F\rvert$ (`snr_reference="peak"`, NDT convention) or RMS |

```python
if snr_reference == "peak":
    ref = float(np.max(np.abs(y_clean)))
...
return ref / 10 ** (float(snr_db) / 20)
```

### Noise colour

- **`"white"`**: $e \sim \mathcal{N}(0, \sigma^2 I)$, exactly the V0 likelihood assumption.
- **`"bandlimited"`**: white noise filtered through a Gaussian pass-band around $f_c$ and rescaled to $\sigma$. This mimics receiver electronic noise after the transducer/amplifier band-pass of a 5 MHz array. The −6 dB full bandwidth is $B = \beta f_c$ (default $\beta$ = 0.7):

```math
|H(f)| = \exp\!\left(-\frac{(f - f_c)^2}{2s^2}\right),\qquad s = \frac{B/2}{\sqrt{2\ln 2}}
```

```python
spec = np.fft.rfft(white, axis=time_axis)
spec *= h                                         # broadcast along the time axis
coloured = np.fft.irfft(spec, n=n_t, axis=time_axis)
return sigma * coloured / coloured.std()
```

Band-limited noise is **correlated in time**, so the V0 i.i.d. likelihood is then deliberately mis-specified. Its effective number of independent samples is roughly $2\,\mathrm{ENBW}/f_s \approx 0.21$ per sample for the defaults, where $\mathrm{ENBW} = \int|H|^2 df = s\sqrt{\pi} \approx$ 2.6 MHz. This is a natural V1 test case.

### Two ways to choose the truth

```python
# (a) library entry as truth: quick plumbing check, but an inverse crime
m = measurement_from_library(lib, true_index=15, snr_db=10, rng=rng)
# (b) any clean signal, e.g. an off-grid toy truth or a separate BristolFE run (preferred)
y, sigma = add_measurement_noise(toy_fmc_truth(2.03e-3, lib), snr_db=-19, rng=rng)
```

Each returns the noisy $y$, the clean truth, $a_\text{true}$ and the $\sigma$ actually used (`SyntheticMeasurement`).
